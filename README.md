# Scalable REST API for E-commerce

## Overview
A REST API for managing products, user authentication, and order placement.

## Features
- User registration and login with JWT authentication.
- CRUD operations for product management.
- Secure order placement and stock updates.

## Installation
1. Clone the repository:
   - git clone https://github.com/your_username/scalable_rest_api.git
   - cd scalable_rest_api

2. pip install -r requirements.txt
3. Start the server:
   - python app.py
